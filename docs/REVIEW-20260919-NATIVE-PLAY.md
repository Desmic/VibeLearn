Both executor surfaces reported browser 1/tab 1. These handles are not globally
unique session identities. The stale root page and resumed learner progress show
that a new tab must not be assumed to isolate the learner/save. The precise
cookie/server identity mechanism was not investigated in this UI-only probe.

## Pipeline consequence

Require a verified disposable learner/session plus single-agent control ownership
before independent play, with executor-scoped tab handles and build identity.
Do not interpret another agent's progress as the current player's own success.
Preserve the observed active-run/reload path as a recovery case.

The next pipeline contract change must distinguish actual live play from reading
captures. Existing execution receipts do not yet prove input execution. No game
acceptance, full motion/audio verdict, deployment or Terminal PM live integration
is claimed by this report.
