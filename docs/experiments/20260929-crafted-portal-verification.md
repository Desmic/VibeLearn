# Crafted portal: matched A/B engineering check

The optional `?study=facade&portal=crafted` asset was compared with `?study=facade` in one sequential HeadlessChrome 154 process. Each variant used a fresh 1102×828 context on ANGLE Intel UHD Graphics/D3D11, the same key/pointer path, a 390×844 portrait check, and distinct captures. The first invocation stopped in the **verifier** before reaching B: its restart helper toggled an already paused menu off, then timed out. After correcting that helper and placing the jamb probe within each variant's collider interval, the sequential A/B rerun passed. The browser closed in `finally`.
