# Synthetic examples

`course-a.json` and `course-b.json` have different route nodes, order, contexts, and activities. They share idempotency and stale-authority frame identities. A additionally targets backpressure; B additionally targets retry policy. `course-c.json` is a non-software argument-analysis route using the same text-response contract.

`catalog/` contains independent immutable registry/content records. Course files contain exact locks to those records, not ownership of them. `historical-snapshot.json` shows the evidence capsule that can be interpreted after course records disappear.

All assessment material and mappings are **draft**. Their rubric anchors illustrate contracts but are not a validated answer key or calibrated difficulty scale. Acceptance tests should explicitly approve test-only fixtures through the same validation boundary, never introduce a production bypass that treats all drafts as approved.

The snapshot timestamp and all identities are synthetic. No attempt, grade, or learner mastery is claimed. Source digests are null because source bytes were not captured; package locks hash the actual supplied metadata JSON files.
